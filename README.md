# 给丸子的圣诞信 🎄

一个送给丸子的圣诞节小页面：柔和的夜空、飘雪、流星，一棵闪着暖光的粒子圣诞树，
旁边是一张点开才会展开的信；背景音乐是页面内实时合成的八音盒版《平安夜》，
不依赖任何音频文件；点击屏幕任意位置会冒出柔和的光点。

## 怎么改成你自己的话

打开 `index.html`，找到最上面的 `CONFIG`：

- `paragraphs`：信的内容，一段一个元素
- `signature`：信末的落款
- 页面标题和卡片上的名字直接在 HTML 里搜索「丸子」替换即可

想换成自己的音乐：在 HTML 里加一个 `<audio id="bgm" src="你的文件.mp3" loop>`，
并把 `Music` 部分改成播放它即可。

## 本地预览

```bash
python3 -m http.server 8765
```

然后打开 http://localhost:8765 。直接双击 `index.html` 也可以看，但部分浏览器会拦截本地音乐播放。
